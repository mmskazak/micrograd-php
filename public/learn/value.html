Value — число, которое помнит, откуда оно взялось

Обычное число после $c = $a * $b — просто 6, откуда оно взялось, уже не узнать. Value хранит результат и вдобавок помнит, из каких чисел и какой операцией его получили. Из этих связей складывается граф вычислений. По нему потом можно пройти назад и узнать, как каждое число влияет на результат.

Пример из видео: нейрон o = tanh(x₁·w₁ + x₂·w₂ + b)

Два входа x, два веса w, bias b и активация tanh — это один нейрон, собранный вручную из Value. Значения как у Карпатого: b = 6.8814 подобран так, что o = 0.7071 и наклон tanh ровно 1 − o² = 0.5, поэтому градиенты получаются круглыми. Двигайте ползунки: граф пересчитывается слева направо (это forward). Клик по прямоугольнику показывает, что лежит внутри объекта.

Обратный проход по шагам

Внутри выбранного Value

Прямоугольник на графе — объект Value. Кружок — операция, которая его породила. У листьев (x₁, x₂, w₁, w₂, b) операции нет: это исходные числа.

Обратите внимание на x₂ = 0: у w₂ градиент 0. Вес, который умножается на ноль, на выход не влияет, как его ни меняй. Сдвиньте x₂, и w₂.grad оживёт.

Код: что именно выполняется на этом шаге

Что такое grad «на пальцах»

grad узла — насколько изменится выход o, если чуть-чуть увеличить этот узел. Проверим без всякого backward: прибавим к каждому листу h = 0.001 и посмотрим, как сдвинулся o.

Числа совпадают: backward вычисляет ровно это, только сразу для всех узлов за один проход, без того чтобы пересчитывать o по разу на каждый вес.

Как объяснить другому

  1. Value — обёртка над числом. Внутри data (само число), prev (из чего получено), op (как) и grad.
  2. Каждая операция (add, mul, tanh) возвращает новый Value и оставляет ему «инструкцию на обратный путь» — функцию backwardFn.
  3. grad отвечает на вопрос: «если это число чуть увеличить, как изменится итог?» Знак показывает направление, величина — силу влияния.
  4. backward() ставит итогу grad = 1 и вызывает инструкции в обратном порядке, так что градиент протекает от итога к каждому листу.
