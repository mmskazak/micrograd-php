Почему все параметры сгоняются в один массив

Внутри сеть вложенная: MLP → слои → нейроны → веса. А циклу обучения нужно одно: «пройди по каждому весу и сделай с ним X» (обнули grad, сдвинь data, сохрани в базу). Метод parameters() на каждом уровне расплющивает вложенность в плоский список, и дальше цикл обучения не знает и не хочет знать, сколько в сети слоёв.

Сеть MLP(2, [3, 2]): 17 параметров

Как это лежит внутри

Что возвращает parameters()

Нажмите «вызвать parameters()».

Наведите на любой элемент плоского списка: подсветится то же самое место в дереве. Это один и тот же объект.

Update через плоский список меняет настоящую сеть

Посчитаем loss на одном примере, сделаем backward и выполним ровно тот цикл, что в проекте: foreach ($model->parameters() as $p) $p->data -= $lr * $p->grad;

Значения в дереве выше изменятся и мигнут.

Почему это работает в PHP

В PHP массивы копируются по значению, а объекты передаются по «ручке» (handle). Когда array_push($params, ...$neuron->parameters()) кладёт Value в новый массив, копируется не объект, а ручка к нему. В плоском списке и внутри нейрона лежит один и тот же объект, и $p->data -= … меняет вес прямо в сети.

Если бы веса были просто float в массивах, parameters() вернул бы копии чисел, и update менял бы копии, а сеть оставалась бы прежней. Включите галочку выше, чтобы это увидеть.

Что даёт плоский список

  • Цикл обучения не зависит от архитектуры. Одни и те же 6 строк zero_grad + update работают для 17 параметров и для 314 (наш проект), для 1 слоя и для 10.
  • Вложенность спрятана. Каждый уровень отвечает только за себя: нейрон отдаёт свои веса, слой склеивает списки нейронов, MLP склеивает списки слоёв.
  • Все параметры видны разом: их удобно посчитать (count(...)), сохранить, загрузить, обнулить.
  • Так же устроен PyTorch: model.parameters() и optimizer = SGD(model.parameters(), lr). Оптимизатор получает плоский список и больше ничего о сети не знает.
В нашем проекте: Trainer::epoch() делает foreach ($model->parameters() as $p) дважды, для zero_grad и для update, и ни разу не упоминает слои.

Как объяснить другому

  1. Сеть — вложенная структура: MLP держит слои, слой держит нейроны, нейрон держит веса.
  2. parameters() на каждом уровне собирает все Value снизу в один плоский список.
  3. Это не копии: в списке лежат ссылки на те же объекты. Изменили вес в списке — он изменился в сети.
  4. Благодаря этому обучение — два простых цикла по списку (обнулить grad, сдвинуть data), одинаковые для сети любой формы.
