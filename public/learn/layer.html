Слой: несколько нейронов смотрят на один и тот же вход

Слой — это просто массив нейронов. Каждый получает весь входной вектор целиком, но у каждого свои веса, поэтому каждый замечает в одном и том же входе что-то своё. Выход слоя — массив ответов всех нейронов. Два числа задают слой: nin — сколько чисел на входе (одинаково для всех нейронов) и nout — сколько нейронов, то есть сколько чисел на выходе.

Сколько параметров в слое

У каждого нейрона nin весов и один bias, значит у слоя nout × (nin + 1) параметров.

Как объяснить другому

  1. Слой — несколько нейронов бок о бок. Вход у всех один, веса у каждого свои.
  2. Каждый нейрон — отдельный «детектор»: один реагирует на одну комбинацию входов, другой на другую.
  3. Выход слоя — массив длины nout, по числу на нейрон. Этот массив станет входом следующего слоя.
  4. Нейроны в слое не знают друг о друге и не обмениваются данными. Это просто цикл foreach.
