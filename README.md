# Micrograd на PHP: распознавание цифр почтового индекса

Учебный проект по лекции Андрея Карпатого
[«The spelled-out intro to neural networks and backpropagation: building micrograd»](https://www.youtube.com/watch?v=VMj-3S1tku0),
переписанной на PHP. Никаких библиотек: весь backprop считает маленький класс `Value`.

Задача: на вход подаются 9 палочек шаблона цифры почтового индекса (каждая 0 или 1),
на выходе 10 нейронов, по одному на каждую цифру 0–9. Побеждает нейрон с самым большим выходом.

```
   ①            палочки:
 ┌────┐         1 верх               6 левая нижняя
②│  ④╱│③        2 левая верхняя      7 правая нижняя
 │ ╱  │         3 правая верхняя     8 нижняя диагональ
 ├─⑤──┤         4 верхняя диагональ  9 низ
⑥│  ⑧╱│⑦        5 середина
 │ ╱  │
 └────┘
   ⑨
```

## Архитектура

```
9 входов (палочки) → 12 нейронов → 8 нейронов → 10 выходов (цифры)
```

- `src/Value.php` — «умное число»: `data`, `grad`, граф вычислений, `add` / `mul` / `sub` / `tanh`, `backward()`.
- `src/Neuron.php`, `src/Layer.php`, `src/MLP.php` — сеть, как в видео: `tanh(b + Σ wᵢ·xᵢ)`.
- `src/Digits.php` — шаблон индекса: какие палочки горят у каждой цифры.
- `src/Trainer.php` — одна эпоха: forward → loss → zero_grad → backward → update.
- `src/WeightStore.php` — веса и история обучения в SQLite (`data/micrograd.sqlite`).
- `public/` — визуализация: `api.php` (JSON) + `index.html` / `app.js` / `style.css`.

Несколько решений, которые отличаются от видео:

- **Вход ±1 вместо 0/1.** Отсутствующая палочка подаётся как −1. При 0 она ничего не добавляла бы в сумму `w·x`,
  и, например, «0» и «8» различались бы для сети только одним входом.
- **Цель +1 / −1** у правильной цифры и у остальных, под диапазон `tanh`.
- **Loss** — среднее по примерам от `Σ (выход − цель)²` (почему среднее, а не сумма, см. конспект).
- **Начальные веса** — случайные в [−1, 1], делённые на √(число входов). Иначе `tanh` на старте часто
  насыщается в ±1, где его производная ≈ 0, и отдельный нейрон перестаёт учиться.

## Запуск

Нужен PHP 8.1+ с расширением `pdo_sqlite`.

```bash
# обучить (по умолчанию 200 эпох, lr = 0.3); --reset начинает со случайных весов
php train.php
php train.php 500 0.2 --reset

# спросить сеть: 9 палочек через запятую
php predict.php 1,1,1,0,0,1,1,0,1     # → 0

# визуализация
php -S localhost:8000 -t public
# открыть http://localhost:8000
```

База `data/micrograd.sqlite` создаётся автоматически при первом запуске (в git её нет).

## Что показывает визуализация

1. **Вход.** Шаблон индекса, палочки включаются кликом. Видно, какой массив уходит в сеть.
2. **Сеть.** Все нейроны и связи. Цвет: синий — плюс, красный — минус; толщина — величина. Три режима:
   - *Сигнал w·x*: что реально течёт по каждой связи для текущего входа (forward);
   - *Веса w*: то, что хранится в SQLite;
   - *Градиенты ∇w*: `∂loss/∂w`, куда сдвинется каждый вес.
3. **Выход.** 10 нейронов-цифр, ответ сети, цель и loss текущего примера.
4. **Нейрон под лупой.** Клик по любому нейрону показывает его граф `Value`
   (`w`, `x` → `×` → цепочка `+` → `tanh`) с `data` и `grad` каждого узла.
   Подсказка при наведении объясняет правило цепи для этого узла на реальных числах.
5. **Обучение.** Кнопка «1 шаг с разбором» проигрывает одну эпоху по стадиям прямо на схеме:
   forward → loss → zero_grad → backward → update. Ниже — график loss по эпохам.
